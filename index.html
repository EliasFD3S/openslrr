Overview

OpenSLRR is a C++ engine for the scripts and cars of Street Legal Racing: Redline. The game data stays yours. This documentation is the modder reference for the natives those scripts call.

Build

Windows x64, Visual Studio 2022, and bgfx. From the repository root:

cmake -S . -B build -G "Visual Studio 17 2022" -A x64

cmake --build build --config Release --target slrr_host --parallel

The executable is build/Release/slrr_host.exe. Point --root at the game install. In this workspace that folder is data/game.

Reading a native

A native is an engine call declared on a script class. Positions are metres. Colors are 0x00RRGGBB.

Yellow means the native is in the host. Orange means the call exists and does less than the original. Red means it is not registered, so a script that needs it will not get the stock behavior.

What is still open

Traffic, water, route queries and most particles are not registered. Pedestrians are a host crowd, not the sidewalk graph. GroundRef.setFog stores values the renderer does not read. Camera.setFog keeps the distances and replaces the script color with the sky.
