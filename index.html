OPEN SLRR

Garage Natives

OpenSLRR is a C++ engine for the scripts and cars of Street Legal Racing: Redline. The game data stays yours. This site is the modder reference for the natives those scripts call.

For modders

A native is an engine call declared on a script class. Parts, chassis, ground, camera, input and sound all go through one. The catalog lists the declarations from the game sources and whether this host implements them.

How to read one

Positions are metres. Colors are 0x00RRGGBB. A green row is in the host. Amber is partial: the call exists and does less than the original. Red is not registered, so a script that needs it will not get the stock behavior.

What is still open

Traffic, water, route queries and most particles are not registered. Pedestrians are a host crowd, not the sidewalk graph. GroundRef.setFog stores values the renderer does not read. Camera.setFog keeps the distances and replaces the script color with the sky.

The engine

Windows x64, bgfx, the stock menus and the garage. Build from the repository root into build/. Point --root at the game install, data/game in this workspace.
